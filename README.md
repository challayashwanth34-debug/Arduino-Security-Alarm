🚨 Arduino Security Alarm System

An Arduino-based security alarm system using an HC-SR04 ultrasonic sensor to detect nearby objects and alert users through a buzzer and LED.

📌 Project Overview

This project uses an ultrasonic sensor to measure the distance of nearby objects. When an object comes within 20 cm, the buzzer and LED are activated to provide an alert.

🛠️ Components Required

- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- 16×2 LCD Display
- Buzzer
- LED
- Jumper Wires
- Breadboard

⚙️ Working Principle

1. The HC-SR04 sensor detects nearby objects.
2. It measures the distance using ultrasonic waves.
3. The distance is displayed on the 16×2 LCD.
4. If an object comes within 20 cm, the buzzer and LED are activated.
5. The system provides an alert for nearby obstacles.
